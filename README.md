## 🚀 Featured Project

### 🍕 MAKI POS: Restaurant Point-of-Sale System

A full **Windows desktop POS application** built for a real fast-food restaurant, from the sales screen to the kitchen printer.

| | |
|---|---|
| **🧱 Stack** | Electron, JavaScript, HTML/CSS, node-thermal-printer, electron-builder |
| **🌐 Localization** | Full RTL Persian UI with Jalali (Shamsi) calendar support |
| **🖨️ Printing** | Dual ESC/POS thermal output: customer receipt and kitchen ticket |
| **🎨 UX** | Dark/light mode, splash screen, themed receipt templates |
| **📦 Delivery** | Packaged as a proper Windows installer (NSIS) |

**Highlights**
- ⚡ Fast sales flow: category tabs, product cards, live cart with quantity controls
- 🧾 Daily order log that resets automatically by Jalali date
- ⚙️ Configurable settings: restaurant info, logo, tax, footer message
- 🗂️ Inline product and category management

> Not a tutorial project. This one survived real printers, real drivers, and real customers.
